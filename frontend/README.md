This is a [Next.js](https://nextjs.org) project bootstrapped with [`create-next-app`](https://nextjs.org/docs/app/api-reference/cli/create-next-app).

## Getting Started

First, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

1. Audio / image file selection from home screen.
2. Able to add rooms and scope of work for each room, so that work is more organised.
3. Able to see uploaded image and uploaded voice with vision analysis and audio transcription.
4. Able to edit scope of work, description, quantity as well as cost for human-in-the-loop process.
5. Able to preview a document before exporting to PDF. 
6. Export to PDF function is under work in progress.
